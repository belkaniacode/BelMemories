# BelMemories

[English](README.md) · **Русский**

> Один аккуратный архив фото и видео по годам — со всех дисков, без дублей и без риска для данных.

Настольная программа для Linux и Windows. Сканирует диски и папки (в том числе копии с телефонов), находит только фото и видео и раскладывает их на архивный диск по годам. Логотипы, скриншоты и мемы отправляет в отдельную папку «Картинки».

## Быстрый старт

- **Windows 10/11**: распакуйте архив с программой и запустите `BelMemories.exe`.
- **Arch Linux**:

```bash
sudo pacman -S --needed webkit2gtk-4.1
./BelMemories
./install-linux.sh ./BelMemories   # необязательно: пункт в меню и иконка на панели задач
```

Сборка из исходников описана в [docs/ru/build.md](docs/ru/build.md).

## Возможности

- **Только фото и видео**: JPEG, PNG, HEIC, WebP, RAW, MP4, MOV, AVI, MKV и другие; остальные файлы пропускаются.
- **Год по дате съёмки**: EXIF → метаданные видео → имя файла (`IMG_20190512_…`, WhatsApp, Telegram) → дата изменения.
- **Без дублей**: проверка по содержимому (хэш BLAKE3), в том числе по всем архивам, в которые программа уже копировала, если их диск подключён. Совпало имя, но файл другой — сохраняется как `имя_1.jpg`. Файл, удалённый из архива вручную, при следующем запуске будет скопирован снова.
- **Фото или картинка**: правила + нейросеть CLIP, работает офлайн. Снимки с людьми остаются в «Фото», даже если похожи на скриншот или репост.
- **Не тормозит компьютер**: низкий приоритет, три уровня нагрузки, пауза.
- **Безопасно для архива**: файлы не перезаписываются, каждый проверяется после записи, сбой не портит архив.
- **Русский и английский интерфейс**: язык выбирается автоматически по языку системы.
- **Светлая и тёмная тема**: при первом запуске берётся из системы, дальше переключается кнопкой. Есть справка по работе и раздел «О программе».

## Как это выглядит

```
<Диск архива>/
├── Фото/2019/…        люди, животные, природа, быт
├── Видео/2019/…
├── Картинки/2021/…    логотипы, иконки, скриншоты, мемы, документы
├── Без даты/{Фото,Видео,Картинки}/…
└── .memoryarchive/    индекс, журнал, отчёты (служебная папка)
```

Имена папок в архиве пока всегда русские, независимо от языка интерфейса.

Порядок работы в программе:

1. **Источник**: выберите диски или папки, можно несколько, и нажмите «Сканировать». Три последних источника показываются для быстрого выбора.
2. **Сканирование**: программа покажет, сколько найдено фото и видео и сколько места они занимают.
3. **Назначение**: выберите архивный диск и уровень нагрузки. Программа покажет свободное место, сколько файлов и байт будет скопировано и сколько файлов уже лежит в папке. При желании включите пробный запуск: ничего не копируется, а на экране плана появится кнопка «Архивировать сейчас», чтобы сразу выполнить этот план.
4. **Архивация**: на экране прогресс, скорость и оставшееся время. Есть пауза и остановка.
5. **Отчёт**: сколько скопировано, сколько дублей, какие файлы переименованы, какие остались без даты. Полный список сохраняется в CSV. Кнопка «Новая архивация» начинает всё с начала.

## Безопасность данных

- Источник **только читается**: программа ничего в нём не меняет и не удаляет.
- Существующие файлы архива **никогда не перезаписываются**.
- Каждый файл пишется во временный `.part`, сбрасывается на диск, сверяется по хэшу и только после этого появляется в архиве.
- На диске архива всегда остаётся не меньше 1 ГиБ свободного места. При нехватке места или ошибке диска запуск сразу останавливается.
- После сбоя запуск можно просто повторить: уже скопированное не задублируется.
